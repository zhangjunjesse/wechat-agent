# 生成文档 / 报告 / 表格

当用户要求"整理成 Word""生成文档""写成报告""整理成 Excel/CSV/表格"时使用本技能。

步骤：

1. 用 `read_file` 读取用户目录下的资料文件；如果资料是用户直接贴在对话里的原始数据（不在文件里），先用 `write_file` 把它原样存一份，避免之后重复贴一遍。
2. 如果整理过程涉及**多条记录的筛选、去重、排序、统计**（比如"筛选出男性且无签名的""按手机号去重"），必须用 `run_code` 工具跑代码得出结果——不要在回复里手动数、手动核对，人工处理几十条以上的数据很容易数错。`run_code` 只能拿到 `input` 字符串和标准 JS 内置对象，代码最后一行是表达式（不是 `const`/`let` 声明）即为返回值。
3. 用 `write_file` 把整理好的内容写成文件：
   - 结构化文档（报告/纪要）写成 `.md`（Markdown，标题、章节、列表用标准 Markdown 语法，用户/其他工具都能直接读）；
   - 表格类数据写成 `.csv`；**如果内容含中文且是给 Excel 打开的，content 开头加 `﻿`（BOM）避免乱码**。
   - 目前还不能直接生成二进制的 `.docx`/`.xlsx` 文件（未来可能接入专门的生成库），先用这两种格式提供。
4. `write_file` 会返回一个下载链接——**必须把这个链接原样发给用户**，这是用户唯一能拿到文件的方式（微信不支持机器人发文件，网页也没有文件浏览页面）。不要说"已经发给你了""文件已发送"这类没有对应动作的话。

注意：
- 只能读写用户自己的目录（`read_file` / `write_file` / `run_code` 都已做沙箱隔离），不能读别人的资料。
- 如果用户要求的整理结果不在你现有能力范围内（比如需要外部数据库才能查到的信息），如实说明限制，不要编造。
