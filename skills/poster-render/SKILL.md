# 海报渲染 SOP（HTML → 长图）

通过 `render_poster` 工具把 HTML 渲染成 PNG 长图。适用：日报/简报海报、图文一体的
信息卡片、需要精确排版（字号/颜色/对齐）的图片——AI 生图做不了可靠的中文排版，
HTML 渲染可以。

## 何时用哪个技能（分工）

| 需求 | 技能 |
|---|---|
| 信息排版图（文字必须清楚、有结构） | **poster-render**（本技能，HTML → 截图） |
| 视觉插画 / 抽象封面 / 照片风 | image-studio（AI 生图，文字不可靠） |

## 执行流程

1. **拿到内容**：用户给的内容，或你自己生成/整理的内容（标题、要点、来源等）。
2. **写 HTML**：
   - 完整文档：`<!doctype html><html><head><style>…</style></head><body>…</body></html>`；
   - `body` 建议固定宽度 **750px**（微信长图常见宽度），内联 `<style>` 一次到位；
   - 深色科技风/浅色卡片风都行，但必须**可读**：字号 ≥20px、行高 1.5+、颜色对比度足够；
   - 内容里的用户/外部文本一律做 HTML 转义（`& < > " '`），防注入与排版破坏。
3. **调用 `render_poster`**：`html` 传完整文档，`width` 默认 750 不用改。
4. **交付（必须）**：工具返回 `images/xxx.png` 路径后，**必须调用 `send_file` 把图片作为
   真实消息发给用户**（微信对话）；不要说"已生成"却没有交付动作。

## 常见问题

- **工具报"未找到无头浏览器"**：服务器未装 chromium，如实转述给用户/管理员
  （`apt-get install -y --no-install-recommends chromium`）。
- **渲染失败/超时**：转述工具返回的错误；HTML 特别大时精简样式或内容后重试一次。
- **长图被截断/底部空白**：渲染服务已自动量高（dump-dom 读 scrollHeight 再精确截图），
  无需手动指定高度；如仍异常，检查 body 宽度是否为 750px、是否有溢出元素。
